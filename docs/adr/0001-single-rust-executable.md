# Ship sarDa as a single Rust executable

Users must get from an SA file to a dashboard with one binary and no language runtime. We rewrote the former Python/pandas script in Rust: the executable generates the dashboard and the Grafana provisioning files itself and embeds the sysstat Containerfile (`sarda containerfile`). The release build links only the system C library (glibc) and libgcc. A fully static musl build is possible wherever the musl target is installed, but it is not part of the tested path. Go was the other serious candidate; Rust was chosen by the maintainer. Crates are few and vendored so the project builds offline (see ADR 0004).
