# SAR CSV Grafana Dashboard

This Grafana dashboard visualizes SAR CSV data generated by `sar-parser`.

## Requirements

- Grafana 7.0+
- `yesoreyeram-infinity-datasource` plugin
- CSV files generated with `sar-parser`

## Dashboard source structure

The committed dashboard JSON is generated from templates:

- `templates/header.json`
- `templates/panels.json`

Regenerate with:

```sh
make build-dashboard
```

## Import in Grafana

1. Configure Infinity data source (`SAR CSV Data Source`)
2. Import `sar-csv.json`
3. Select that data source
