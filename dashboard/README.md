# SAR CSV Grafana Dashboard

This Grafana dashboard visualises system activity report (SAR) data from CSV files
generated by `sar-parser`.

## Requirements

- Grafana 7.0+
- [`yesoreyeram-infinity-datasource`](https://grafana.com/grafana/plugins/yesoreyeram-infinity-datasource/) Grafana plugin
- CSV files produced by `sar-parser`

## Dashboard source

The committed `sar-csv.json` is **generated** from a [jsonnet](https://jsonnet.org/)
source that uses the [grafonnet](https://github.com/grafana/grafonnet) library:

| Path | Purpose |
|---|---|
| `jsonnet/main.jsonnet` | Dashboard definition – rows, panels, variables |
| `jsonnet/lib/panels.libsonnet` | Reusable helper functions (CSV targets, panel/row factories) |
| `jsonnet/g.libsonnet` | Grafonnet import alias |
| `vendor/` | Vendored grafonnet v11.4.0, docsonnet and xtd libraries |
| `jsonnetfile.json` | Dependency manifest for jsonnet-bundler |

`sar-csv.json` is listed in `.gitignore`; always re-generate it before importing.

### Regenerate the dashboard JSON

```sh
make build-dashboard
```

This runs `jsonnet -J dashboard/vendor dashboard/jsonnet/main.jsonnet > dashboard/sar-csv.json`.

The `jsonnet` binary must be on your `$PATH` (`make install-jsonnet` installs it via Go).

### Extend the dashboard

1. Open `jsonnet/main.jsonnet` and add/edit panel or row definitions.
2. To add a new metric panel type, extend `jsonnet/lib/panels.libsonnet`.
3. Regenerate with `make build-dashboard`.

## Import into Grafana

1. Configure the Infinity data source:
   - **Connections → Data Sources → Add new** → **Infinity**
   - Name it `SAR CSV Data Source` (or any name matching `/^SAR.*/`)
2. Import the dashboard:
   - **Dashboard → New → Import**
   - Upload `dashboard/sar-csv.json`
3. Set the `baseurl` variable to the base URL that serves your CSV files.
